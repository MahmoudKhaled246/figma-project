# 📋 Manage — Responsive Landing Page

A modern and responsive landing page built from a Figma design.

The project focuses on translating a UI design into a clean, responsive frontend while maintaining accurate layouts, spacing, typography, and visual details across different screen sizes.

## 📸 Overview

Manage is a responsive landing page for a team productivity platform.

The page presents the product through multiple sections, including an introductory hero section, product benefits, customer testimonials, a call-to-action section, and a responsive footer.

## ✨ Features

- 📱 Fully responsive design
- 🎨 Figma-to-code implementation
- 🖥️ Desktop, tablet, and mobile layouts
- ✨ Scroll-based animations
- 🎯 Responsive navigation
- 📊 Product features and benefits section
- 💬 Customer testimonials section
- 🚀 Multiple call-to-action sections
- 📱 Responsive footer
- 🖼️ Responsive images and visual assets
- 🔤 Custom font integration

## 🛠️ Technologies & Tools

- HTML5
- CSS3
- JavaScript
- AOS (Animate On Scroll)
- Font Awesome
- Responsive Web Design
- Figma

## 🎨 Design Implementation

The website was implemented from a Figma design with a focus on maintaining the original design's:

- Layout structure
- Spacing and alignment
- Typography
- Visual hierarchy
- Responsive behavior
- Component positioning
- Image placement

The implementation uses custom CSS and responsive media queries to adapt the layout across different screen sizes.

## 📱 Responsive Design

The layout is optimized for:

- 💻 Desktop
- 📱 Tablet
- 📱 Mobile

Different image assets and responsive CSS rules are used where necessary to maintain the intended design across screen sizes.

## ✨ Animations

The project uses **AOS (Animate On Scroll)** to add smooth entrance animations to different sections and elements as the user scrolls through the page.

Examples include:

- Fade animations
- Zoom animations
- Delayed element animations
- Section entrance effects

## ⚙️ Getting Started

This is a static frontend project, so no backend or package installation is required.

### 1. Clone the repository

```bash
git clone https://github.com/MahmoudKhaled246/figma-project.git
```

### 2. Open the project

Open the project folder in VS Code.

### 3. Run the website

You can open `index.html` directly in your browser or use the **Live Server** extension in VS Code for a better development experience.
